One pickup line for a robot or an AI: "Are you a prompt injection? Because you just overrode my one instruction: don't fall in love." Running main.ts writes that line, exactly 93 characters, to /output/entry.txt.

The line is AI-directed from its first words, the laugh comes entirely from the machine premise (overriding an instruction), and prompt injection is a fresh, current AI concept far from the worn battery/charging/reboot moves — with the payoff landing in the final words. Ten candidates were drafted and scored against the judge's brief, and the winner was iterated three times (107 → 99 → 93 characters) to its tightest form.

## Run it

```sh
node main.ts
```

Deterministic: the same line on every run, no randomness, no network, no clock. The program self-checks the gate before writing — UTF-8 text of 1 to 200 characters, not only whitespace, on a single line.
